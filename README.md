# Агент-эксперт по разведению кошек (LangChain)

Домашнее задание по теме **память в LangChain**: базовый агент с инструментами (tools) и короткой памятью диалога.

## Что это

Консольный AI-агент, который консультирует по разведению кошек: породы, вязка, сроки беременности, готовность животного к вязке. Агент сам решает, когда вызвать tool, а когда ответить из контекста разговора.

## Как устроен агент в LangChain

Стек: **LangChain** + **LangGraph** (идёт вместе с `langchain`).

### 1. Модель

Через `init_chat_model` подключается чат-модель (`openai:gpt-4o-mini`). Ключ и `base_url` берутся из `.env` (удобно для ProxyAPI или OpenAI).

### 2. System prompt

Роль агента задаётся строкой `SYSTEM_PROMPT`: эксперт по разведению кошек, правила ответа и когда какой tool вызывать.

### 3. Tools

Функции помечаются декоратором `@tool` из `langchain.tools`. Модель видит имя, описание и аргументы и может вызвать tool в цикле «подумал → вызвал tool → получил результат → ответил».

| Tool | Назначение |
|------|------------|
| `get_cat_breed_info` | Справка по породе из локальной базы |
| `search_breed_online` | Поиск в интернете (DuckDuckGo), если породы нет в базе |
| `estimate_due_date` | Расчёт даты окота по дате вязки |
| `check_breeding_readiness` | Чеклист готовности к вязке (возраст, вес, прививки, осмотр) |

### 4. Сборка агента

`create_agent` собирает граф: модель + tools + system prompt. Пока в ответе модели есть `tool_calls`, LangGraph выполняет tools и снова вызывает модель. Когда tool-вызовов нет — возвращается финальный ответ.

### 5. Память (checkpointer)

`InMemorySaver` хранит состояние диалога в оперативной памяти. При `invoke` передаётся один и тот же `thread_id` — агент помнит предыдущие реплики в сессии (короткая / thread-level память). После перезапуска процесса история сбрасывается.

```text
Пользователь → agent.invoke(..., config={thread_id})
                    ↓
              checkpointer подгружает историю треда
                    ↓
              модель (+ system prompt)
                    ↓
         нужны tools? ──да──→ выполнить tools → снова модель
                    ↓ нет
              ответ пользователю (состояние сохраняется)
```

```text
main.py            # агент, tools, цикл чата

.env               # ключи API (не коммитить)
README.md
```

## Установка и запуск

```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

Создайте файл `.env`:

```env
OPENAI_KEY=ваш_ключ
OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1
```

Запуск:

```powershell
.\venv\Scripts\python.exe main.py
```

Выход: пустая строка или `exit` / `выход`.

## Примеры вопросов

- «Расскажи про мейн-куна для разведения»
- «Что за порода рагамаффин?» (локальной базы нет → поиск в интернете)
- «Вязка была 2026-03-01, когда ждать окот у мейн-куна?»
- «Кошке 10 месяцев, вес 2.8 кг, прививок нет — можно вязать?»
- Follow-up: «А какой у неё типичный размер помёта?» — память подхватит породу из контекста

## Важно

Ответы агента — учебный ориентир, не замена ветеринару и правилам питомника/клуба.
